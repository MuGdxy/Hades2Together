# Hades2Together

四个人在同一局哈迪斯 2 里打同一批怪物。权威是一个正在运行的游戏进程：主机玩家的进程，或者一台不占玩家席的专用进程。客人只发送操作，并按快照把人和怪画出来。

当前是第 0 阶段。规则、协议和模块边界可以离线测试。`hack/game.lua` 是以后唯一允许调用游戏的文件，现在调用它会拒绝执行。

## 模块

| 路径 | 谁加载 | 做什么 |
| --- | --- | --- |
| `protocol/` | 两边 | 消息、编解码、席位 |
| `net/` | 两边 | 传输。现在只有内存回环 |
| `gameplay/` | 权威 | 纯规则：队伍、死亡、血量、祝福归属 |
| `authority/` | 权威 | 把规则产出的命令交给 hack |
| `hack/engine.lua` | 两边 | hack 接口 |
| `hack/fake.lua` | 测试 | 假世界，一只怪一条血 |
| `hack/game.lua` | 游戏进程 | 活游戏绑定，尚未实现 |
| `client/` | 客人 | 采集本机输入 |

`serve+play` 加载全部。`serve` 不采集本地输入。`play` 不加载权威循环。角色写在 `src/config.lua`。

## 测试

在仓库根目录执行：

```powershell
lua tests/run.lua
```
