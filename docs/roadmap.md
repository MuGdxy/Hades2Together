# 开发路径

开发优先使用 CLI、Lua 热更新和游戏外的控制页。通过游戏内开发 GUI 的源码查找游戏 API，需要操作时在 CLI 提供入口。当前可以从 PowerShell 冷启动 `F_Combat01` 并识别英雄。标题画面的命令派发和四席原生输入仍待解决。见 [当前卡点](blockers.md)。

离线测试在仓库根目录执行 `lua tests/run.lua`。这一套测试必须在每个阶段结束后仍然通过。

本机 CLI 的验证项包括：

- `lua tests/run.lua` 通过。
- `.\tools\h2t.ps1 player add`、`player remove`、`status` 能排队并读回席位。
- 游戏测试房间识别英雄。当前 `play` 对无法提交的原生输入返回 `unsupported`。
- 标题画面接收并处理新的 `enter` 命令。这一项仍需游戏侧派发入口和可用的默认地图资产。

## 阶段 0：边界

已完成，在 `main` 上。

协议、席位、队伍、死亡、血量放大、祝福归属、权威循环和假世界可以不启动游戏就跑通。`hack/game.lua` 有全部方法名，调用时会拒绝执行。插件能被 Hell2Modding 加载，但只打日志，不挂钩子。

## 阶段 1：本地开发控制与权威引擎适配

目标是让权威进程将四个网络席位的输入交给对应的原生角色，并共同攻击同一个敌人。原版当前英雄上下文、武器与索敌限制由适配层调查。网络闭环与原生角色适配并行验证。

### 里程碑 1：本地控制页

主菜单是原生屏幕，游戏窗口不在前台时也会停止模拟。控制页因此由 `tools/h2t.ps1` 单独提供，地址是 `http://127.0.0.1:27779/`。命令先排队，游戏回到前台时执行。用法见 [cli.md](cli.md)。

假玩家在这一里程碑里是席位，还不是世界里的单位。

完成标准：

- 游戏启动后，浏览器打开该地址能看到控制页和当前席位。
- 页上的「加入假玩家」会多出一个席位，刷新后还在。
- `lua tests/run.lua` 通过。

### 里程碑 2：四个单位打同一只怪

顺序：

1. 在 `Ship` 旁装上 Hell2Modding，用开发目录里的 `src` 作为插件。
2. 验证 `BindHero` 能把四个网络席位映射到权威进程中的角色。现有零售接口的映射能力仍待确认。
3. 验证 `PushInput` 能把各席位的操作交给对应角色的原生输入通道，保留游戏的输入检查和状态逻辑。
4. 实现 `SetAggroTargets`，敌人可以把四个人都当作目标。
5. 实现 `SetCamera`，镜头框住还活着的英雄。
6. 把 `ReadActors` 和 `PullEvents` 接到权威循环上。在训练场或一间房里打一只怪，确认 `ReadActors` 里这个敌人只有一条 `hp`，两个人打它时这条血往下掉。

完成标准：

- 权威进程中的 4 个英雄单位各接收对应客户端的操作。
- 对同一个敌人 id 的伤害落在同一条血上。
- 敌人的目标列表里可以出现这 4 个单位。
- 镜头能框住存活的英雄。
- 新增的游戏调用只在 `src/hack/game.lua`。
- `lua tests/run.lua` 通过。

祝福界面、选门和专用服务器的后台模拟在后续阶段处理。

## 阶段 2：独立客户端与权威进程

四个独立客户端各读取自己的玩家输入。权威分配席位，接收 `Input`，通过适配层提交给对应实体，再广播完整 `Snapshot` 和裁决。客户端通过 `SuppressLocalSim` 抑制本地遭遇，通过 `ApplySnapshot` 用同一个权威 tick 的状态呈现人和怪。

- 传输验证使用一个占 0 席的 `serve` 和四个独立的 `play` 进程，在 localhost 通过 TCP 运行。通过 [五进程测试](network.md) 验证输入归属、完整快照与裁决、拒绝规则和断开重连。
- 正式游戏验证需要权威适配层和四个游戏客户端。一个客户端的原生攻击由对应权威角色执行，四个客户端呈现同一个敌人 ID 和同一份权威血量。

## 阶段 3：跑起来的规则

把死亡、开门、路线和祝福接成命令。祝福通过 `RunAsHero` 进入游戏自己的抽取。死亡后是继续还是结束，以 `gameplay` 的命令为准，再由 `hack/game.lua` 执行。

完成标准：一人倒下时其他人能继续打同一只怪；全灭时权威发出 `EndRun`；一次祝福只发给命令里指定的那个席位。

## 阶段 4：专用服务器

同一套 `serve`，玩家席为 0。实现 `SetFocusTick`，窗口在后台时模拟不停止。断线的名字回到原来的席位。

完成标准：权威进程没有本地英雄，客人仍能打同一只怪；把权威窗口切到后台后，客人的输入仍被结算。

## 阶段 5：手感

本机移动先预测，远程的人和怪按快照插值。远程动画先做待机、跑和冲刺。

完成标准：客人自己的移动在输入后立刻动起来，权威纠正位置；远程单位不在两拍快照之间停住。

## 阶段之间怎么推进

本地控制、原生角色适配和离线传输可以各自验证。正式联机验证依赖完成原生角色适配。游戏调用写进 `hack/game.lua` 并使用明确的接口，`gameplay` 和 `authority` 只通过接口访问。
